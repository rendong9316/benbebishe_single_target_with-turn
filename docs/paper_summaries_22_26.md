### 论文22: Feature aided switching model set approach for maneuvering target tracking

**研究背景与动机：** 机动目标跟踪是雷达 surveillance、导弹防御和自动驾驶等领域中的核心问题。传统交互多模型（IMM）算法通过并行运行多个运动模型并融合估计结果来应对目标机动，但其性能高度依赖于预设的固定模型集合。当目标执行复杂机动时，固定模型集往往无法及时匹配目标实际运动状态，导致跟踪性能下降。此外，模型间频繁的无效切换会引入估计抖动，进一步恶化跟踪精度。因此，如何根据目标的实时运动特征智能选择适配的模型集合，成为提升IMM跟踪性能的关键问题。

**主要方法与创新点：** 本文提出了一种基于特征辅助的切换模型集方法（Feature-Aided Switching Model Set Approach），将目标运动学特征提取与IMM框架相结合，实现对机动模式的智能识别与模型集动态切换。具体而言，算法从目标的连续测量序列中提取关键运动学特征（如速度、加速度、转弯率等），并基于这些特征构建模型选择准则，以判断当前目标所处的机动阶段和合适的运动模型集合。与传统IMM采用固定转移概率矩阵不同，该方法根据特征检测结果动态调整模型集的构成，仅在目标确实发生机动时才切换到包含高机动模型的集合，从而减少了不必要的模型切换次数。算法的核心创新在于设计了特征驱动的模型集自适应机制，使IMM能够在保持计算效率的同时显著提升对复杂机动的响应能力。

**实验/仿真设置与结果：** 仿真采用了具有复杂机动模式的 realistic target trajectory，包括直线匀速飞行、突然加速、急转弯等多种机动阶段的组合。实验对比了所提方法与采用固定模型集的传统IMM算法在位置RMSE、速度RMSE和模型切换次数等指标上的表现。结果表明，在目标执行复杂机动阶段，所提方法的跟踪精度较传统IMM提升了约20%~35%，同时模型切换次数减少了约40%，有效抑制了不必要的模型切换带来的估计抖动。在长时间跟踪场景下，该方法也展现出了更好的稳定性和鲁棒性。

**结论与应用价值：** 本文提出的特征辅助切换模型集方法为机动目标跟踪提供了一种新的思路，通过引入特征驱动的模型集自适应机制，有效平衡了跟踪精度与计算复杂度。该方法在复杂机动场景下具有显著优势，可应用于雷达跟踪系统、导弹制导、无人机目标跟踪等实际工程场景。未来的工作可进一步探索多特征融合策略以及在线特征学习机制，以增强方法对不同机动模式的泛化能力。

### 论文23: IMMNet: Hybrid Fusion of Model-based and Data-driven Approaches for Maneuvering Target Tracking

**研究背景与动机：** 三维空间中机动目标的跟踪是一个极具挑战性的问题，源于目标运动动力学的高度复杂性和模型失配。传统的基于模型的IMM算法虽然具有良好的可解释性和贝叶斯推理结构，但其性能严重依赖于精确的状态空间建模和准确的噪声协方差矩阵估计。在模型失配、参数漂移或环境扰动等实际场景中，其性能可能显著下降。另一方面，基于数据的深度学习方法虽然具有较强的自适应能力和对未知噪声的鲁棒性，但普遍存在可解释性差、参数量大、依赖固定长度观测窗口等问题，限制了其在实时雷达应用中的部署。因此，如何将模型驱动方法的可解释性与数据驱动方法的适应性有机融合，成为一个亟待解决的关键问题。

**主要方法与创新点：** 本文提出了IMMNet，一种新型混合模型/数据驱动的机动目标跟踪算法，将IMM框架的可解释结构与神经网络的可学习组件相结合。具体而言，IMMNet用基于Transformer的运动模式分类器替代IMM中固定的马尔可夫转移概率更新机制，使算法能够捕捉目标运动的复杂时空依赖性，无需依赖马尔可夫假设；同时，用基于KalmanNet的混合模型/数据驱动滤波器替代传统卡尔曼滤波器，通过神经网络模块自适应学习Kalman增益，从而适应未知噪声统计特性并缓解模型失配。IMMNet采用四个并行KalmanNet实例作为专家跟踪器，分别对应CV（匀速）、CA（匀加速）、CT+（最大正转弯率）和CT-（最大负转弯率）四种运动模型。训练采用两阶段分布式策略：第一阶段独立预训练四个KalmanNet跟踪器，第二阶段进行端到端联合微调，优化目标是跟踪精度与模式分类准确率的加权和。

**实验/仿真设置与结果：** 本文构建了一个大规模三维机动目标轨迹数据集（3D-LAST），包含10万个轨迹，每个轨迹覆盖400秒，目标距离雷达0.5~20海里，速度0~340 m/s，转弯率-10°/s至+10°/s，每个轨迹包含随机切换的三种运动模式。在测试集上，IMMNet在各空间维度上的平均RMSE仅为0.29米，显著优于IMM-Accurate（已知最优参数，1.32米）、IMM-Min（仅知噪声下界，3.29米）和IMM-Max（仅知噪声上界，4.55米）。在模式切换点附近，IMMNet的跟踪误差远低于对比算法，展现出对机动模式的快速响应能力。

**结论与应用价值：** IMMNet通过深度融合模型驱动方法的结构化推理能力和数据驱动方法的自适应学习能力，在复杂三维机动目标跟踪任务上取得了显著优于纯模型驱动方法的性能。该方法不仅保持了IMM框架的可解释性，还有效缓解了模型失配和噪声参数不确定性带来的性能退化问题，为雷达跟踪系统的实际应用提供了鲁棒、可解释且高效的解决方案。未来工作将聚焦于增强算法的噪声鲁棒性，并将其扩展至多目标跟踪场景。

### 论文24: SAFE IMM: Stochastic Adaptive Filtering for Enhanced Maneuvering Target Tracking

**研究背景与动机：** 机动目标的跟踪要求估计器既具备快速响应能力又具有鲁棒性。交互多模型（IMM）滤波器是跟踪领域的标准方法，但通过高斯混合融合模型的方法在机动期间往往响应滞后。最近出现的赢者通吃（WTA）方法虽然反应迅速，但可能产生估计不连续性。此外，IMM在资源受限的移动平台上的计算开销较大，且对 corrupted measurements 敏感。现有方法要么融合模型（IMM），要么强制执行硬选择（WTA），但均未显式控制从混合融合切换到单模型选择时的输出连续性。因此，需要在响应速度和估计平滑性之间寻求平衡。

**主要方法与创新点：** 本文提出SAFE-IMM（Stochastic Adaptive Filtering Enhancement for IMM），一种轻量级IMM变体，专为移动和资源受限平台上的目标跟踪设计。核心创新是引入了一个安全协方差感知门（safe covariance-aware gate），该门在蕴含的混合估计到赢家的跳跃被证明是有界的时才允许WTA操作。具体而言，算法通过计算赢者模型与其他竞争模型之间的均值偏移量（drift bound），并结合协方差几何信息（Mahalanobis距离），判断WTA触发是否会导致估计不连续。若漂移上界B小于阈值ε_WTA，则输出赢者模型的单点估计；否则输出标准的高斯混合估计。此外，SAFE-IMM还集成了Student-t似然函数以增强对杂波和异常值的鲁棒性，以及基于广义似然比（GLR）、熵和赢者连击的自适应转移概率矩阵（TPM）以适应不同的机动状态。

**实验/仿真设置与结果：** 算法在仿真和nuScenes前向雷达数据上进行了验证。仿真设置包括三个目标（T1近匀速、T2中等机动、T3尖锐加速），采用CV和CA两种模型，Δt=0.1s，总时长30s。在Profile 1（高位移噪声）下，SAFE-IMM的平均位置RMSE为[0.135, 0.179]米，OSPA为1.070；在Profile 2（高速度噪声）下，平均位置RMSE为[0.017, 0.012]米，OSPA为0.683。ε门控满足率达到100%。在nuScenes前向雷达验证集上，SAFE-IMM的AMOTA为7.24%，MOTA为18.5%，ID切换次数仅为37次，比基线IMM减少了60%。计算效率方面，SAFE-IMM达到229.6 FPS（IMM部分）和17.9 FPS（端到端），显著优于非线性基线（8.8/187.9 FPS）和标准IMM（9.3/198.1 FPS）。

**结论与应用价值：** SAFE-IMM通过协方差感知门控机制，在保证WTA快速响应优势的同时避免了估计不连续性，结合Student-t似然和自适应TPM，实现了高精度、高鲁棒性和实时性的平衡。该方法计算开销低、数值稳定性好、对杂波具有鲁棒性，适用于资源受限的移动平台（如无人机、移动雷达站）上的机动目标跟踪应用。未来工作可扩展至多传感器融合和类别感知跟踪。

### 论文25: PCRLB Geometry for IMM Tracking Performance Analysis

**研究背景与动机：** 在后验Cramer-Rao下界（PCRLB）为雷达跟踪性能评估提供了理论基准。然而，在 realistic radar tracking 中，目标测量不确定性（TMU）——包括检测概率和测量误差协方差——显著受到目标-雷达（T2R）几何构型的影响。现有PCRLB很少深入研究T2R几何对TMU及状态估计均方误差（MSE）的根本影响，导致下界过于保守。此外，现有雷达轨迹控制方法通常需要穷举所有可行的控制指令来生成伪理想测量集（PIMS），计算复杂度较高。因此，建立更精确的PCRLB并用于雷达轨迹优化具有重要的理论和应用价值。

**主要方法与创新点：** 本文提出改进的PCRLB（IPCRLB），全面考虑了杂波环境中雷达测量的起源不确定性（MOU）和依赖于T2R几何的TMU。主要贡献包括：（1）推导了具有移动接收机和发射机的双基雷达在任意信号类型下的目标测量误差协方差的广义模型，并给出了近似解以刻画T2R几何对误差协方差的影响；（2）严格推导了考虑MOU和几何依赖TMU的IPCRLB，将检测概率和测量误差协方差均视为状态依赖参数，在关于目标状态求对数似然时进行处理；（3）定义了信息增益因子（IGF），量化因考虑检测和测量误差协方差对T2R几何依赖性而产生的额外Fisher信息，当忽略这种依赖性时IGF退化为零。数值研究表明，随着TMU增大，IPCRLB相对于现有下界的改进程度也越大。

**实验/仿真设置与结果：** 仿真考虑了2D监视空间中的双基雷达跟踪机动目标场景，采用ATSC信号作为照射信号。通过改变目标方位角θk和目标距离RR,k来生成多样化的T2R几何构型。结果表明：（1）TMU随DOA θk的变化显著，当θk=180°时（发射机-目标-接收机共线），测量误差标准差σd、σv和σθ达到最小值，检测概率Pd达到最大值；（2）IPCRLB的迹在各种T2R几何构型下均显著低于传统EFIM和PCRLB，且差距随TMU增大而扩大；（3）将IPCRLB的预测迹作为代价函数应用于雷达轨迹控制，能够有效优化T2R几何，获得更高质量的Target measurement，相比现有轨迹控制方法显著改善了跟踪精度。

**结论与应用价值：** 本文推导的IPCRLB为杂波环境中雷达跟踪提供了更准确的性能下界，揭示了T2R几何对跟踪性能的深刻影响。该方法避免了传统轨迹控制中繁琐的伪理想测量集枚举操作，为双基雷达系统的轨迹优化提供了有效工具。研究成果可应用于雷达资源管理、传感器组网和自主导航等场景。

### 论文26: EKF/UKF maneuvering target tracking using coordinated turn models with polar/Cartesian velocity

**研究背景与动机：** 机动目标跟踪中，协调转弯（Coordinated Turn, CT）模型是描述目标转弯运动的经典选择。然而，状态空间中速度分量的不同表示方式（极坐标vs笛卡尔坐标）对EKF和UKF的跟踪性能有显著影响。传统方法通常固定使用某种坐标表示，缺乏针对不同跟踪场景的系统性比较。此外，在长距离跟踪中，不同坐标系的数值稳定性差异也会影响滤波器的可靠性和精度。因此，系统研究不同状态表示方案对EKF/UKF跟踪性能的影响，具有重要的理论意义和实用价值。

**主要方法与创新点：** 本文系统研究了在极坐标和笛卡尔坐标系下，EKF和UKF利用协调转弯模型进行机动目标跟踪的性能。重点比较了不同速度表示方案（极坐标速度vs笛卡尔坐标速度）在状态空间中的跟踪精度和计算效率。文章建立了完整的状态空间模型，包括CV、CA和CT等多种运动模式的转换关系，并推导了在极坐标和笛卡尔坐标下的量测方程和状态转移方程。通过引入不同的状态表示方案，全面评估了EKF和UKF在处理高度非线性协调转弯机动时的性能差异。

**实验/仿真设置与结果：** 仿真设置了多种机动场景，包括低速直线运动、高速转弯、加速度变化等典型机动模式。实验指标包括位置RMSE、速度RMSE、计算时间以及滤波器发散率。结果表明：（1）对于高度非线性的协调转弯机动，UKF显著优于EKF，在位置跟踪精度上提升了约30%~50%，且在剧烈机动阶段不易发散；（2）极坐标表示在长距离跟踪中提供了更好的数值稳定性，尤其在目标距离雷达较远时，极坐标方案的位置误差增长更为平缓；（3）笛卡尔坐标表示在近距离跟踪中具有更直接的速度估计精度，但在远距离场景下数值条件较差。不同坐标表示的性能优劣与跟踪距离、机动强度和噪声水平密切相关。

**结论与应用价值：** 本文提供了关于EKF/UKF在协调转弯模型下不同坐标表示方案的全面性能比较，为实际雷达跟踪系统中的坐标系和速度表示选择提供了实用的指导原则。研究结论表明，UKF配合极坐标速度表示适合远距离、高机动场景；而笛卡尔坐标表示适合近距离、中等机动场景。这些结果为实际工程应用中的滤波器设计和参数配置提供了重要参考。
