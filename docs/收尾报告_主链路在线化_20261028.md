## 1. 本次工作概述

之前两条线并存：`run.m`（批处理，整段预计算匹配+融合）与 `run_online.m`（在线但没接入主链路）。本次把两者合并成 **唯一主入口 `run.m`**，实现"一条干净的全在线主链路，逐阶段对应论文章节"。

交付形态（契约第 1 节）：

```
run.m  ← 唯一主入口（9 阶段，逐帧推进）
 ├─ Stage 0  场景构建        → 第2章 2.3 数据驱动场景

 ├─ Stage 2  点迹生成        → 第2章 2.2 双基地天波量测模型

 ├─ Stage 6  航迹融合(在线)  → 第5章 SCC/BC/CI/FCI
 └─ Stage 7  指标与出图      → 第6章 6 项考核指标
```

## 2. 已完成（成果）

### 2.1 主链路统一 — `run.m`
- 重写为唯一 **9 阶段全在线主链**，`Stage 2~6` 全部在 `for k = 1:n_frames` 内逐帧推进，帧 k 仅读取第 k 帧及以前（因果性硬约束）。
- 新增流式逐帧点迹 `generate_one_frame_detections`，消除原批处理"整段预计算"。
- 时间网格截断修复：`max_frames < n_frames` 时 `t1_grid/t2_grid` 越界问题已修。
- `run_online.m` 改为薄壳，提示废弃并转发到 `run()`；`experiments/run_online_fr24.m` 已改为调用 `run()`。

### 2.2 关联策略包（可插拔）— `tracker/+online_assoc/` + `tracker/+online_strategies/`
- 四种在线配对器，统一接口 `init_strategy / update_candidates`：
  - `nn`（朴素最近邻，无门限）
  - `sequential`（序贯马氏通过率）
  - `dualgate`（位置+马氏+速度一致性三判据）
  - `mewf`（多证据滚动累积，单调确认，天然适合在线）
- 证据累积器 `evidence.m / accumulate_evidence.m`：距离/马氏/速度/连续段四项在"截至本帧"的共现帧上滚动累计（非全部共现帧均值），保证确认是单调事件。
- **关键设计**：M/N 序贯确认与 1v1 指派由融合中心统一执行，四种方法只比"证据本身好不好"，保证对比公平。

### 2.3 融合包（可插拔）— `fusion/+online_fuse/`
- 四种算法 `scc / bc / ci / fci`，统一接口 `init / fuse_step`（逐帧）。
- **BC 做真 BC**：`P12(k)=F·P12(k-1)·F'+0.5·Q`，并加 `bc_min_p12_scale`（默认 0.05）保底缩放，避免退化成 SCC。断连时 `P12` 置零。
- 几何过程噪声 `process_noise_geo.m`、协方差正则 `regularize_cov.m` 已配套。

### 2.4 融合中心改造 — `tracker/central_track_manager.m`
- 改为**策略驱动**：`[state, frameLog] = central_track_manager(action, varargin)`，持有 `.CT`（系统航迹）、`.S`（关联策略状态）、`.F`（各方法融合状态）。
- 流程：预测 → 释放失联源(K_loss) → 策略产出候选 → **贪心 1v1** → M/N 确认 → 重复航迹合并+历史拼接 → 多方法融合 → 删无源 → 新建系统航迹。
- **关键 bug 修复**：原"源保护"逻辑 `ismember(c.r1_id, prot1)` 会丢弃 r1 已属某 CT 的候选，导致配对永不发生；改为 `used_r1/used_r2` 1v1 约束。
- 新增 `source_taken_by_other` 防两个 CT 抢同一局部航迹（重复合并时漏合问题已修）。

### 2.5 评测与出图
- `evaluation/evaluate_online_fusion.m`：逐帧融合快照 → 配对×方法结构；真值时间基由 `k*dt` 修正为 `(k-1)*dt`（修复 SCC 12.47 km 虚高）。
- `evaluation/evaluate_paper_metrics_online.m`：6 项论文指标（RMSE、航迹长度、匹配正确率/召回、虚假航迹率、融合覆盖率、共同帧 RMSE、一致性 NEES/ρ/理论界）。
- `visualization/plot_online_fr24.m` 适配新指标结构。
- `simulation/calibrate_radar_bias.m` 从 `run.m` 抽出，支持 `'none'/'mean'/'mle3'` 配准模式。

### 2.6 单元测试（全部通过）
- `validation/run_online_assoc_tests.m`（6 项）：各方法初始化、nn 无门限、sequential 马氏门限、dualgate 三判据、mewf 单调累积、因果性。
- `validation/run_online_manager_tests.m`（6 项，原 `run_online_fusion_tests.m` 误装 manager 测试，已改名）：系统航迹预建、M/N 确认帧=M+1=4、源独占、因果性、重复合并历史拼接、长度不缩短。
