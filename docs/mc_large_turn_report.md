**日期：** 2026-07-26  
**场景：** 4 个真 180° 半圆大转弯场景（整改后）  
**实验：** 3 种子 × 4 场景 × 4 配置 = 48 次完整 run  
**数据：** `results/mc_large_turn.mat`

## 二、核心结论

### 结论 1：在真大转弯下，所有 IMM 自适应 PI 方案都无效或有害

```
平均改善: Cfg51 = -0.9%, SigOnly = -1.7%, Cfg51+Sig = -7.7%
```

- **Cfg51**（固定参数调优）：基本无效（-0.9%），说明 ct_dwell/Q_scale 的调参在真大转弯上没帮助
- **SigOnly**（Sigmoid 自适应 PI）：略有恶化（-1.7%）
- **Cfg51+Sig**（组合）：明显恶化（-7.7%），特别是 right_rate_0p7 灾难性恶化 -19.7%

### 结论 2：Default 基线已经是最强的

在真大转弯场景下，**默认 IMM 配置（固定 Pi）的平均 RMSE 最低（6.84 km）**。所有"改进"尝试都让它变差。

这与小转弯场景（Phase 3/4 报告）的结论完全相反——那时 Cfg51+Sigmoid 看起来有效（+6%），但那是在错误的 47° 小转弯上得到的假象。

### 结论 3：唯一有效的是 left_rate_1p3

只有 `left_rate_1p3` 场景下，所有方案都有效（Cfg51 +2.6%, SigOnly +5.4%, Cfg51+Sig +3.0%）。

**为什么？** 关键在于真实转弯率与 CT 模型内置转弯率的关系：

| 场景 | 真实 turn_rate | CT 模型内置 | 关系 | 自适应效果 |
|------|---------------|------------|------|-----------|
| left_rate_0p7 | 0.7°/s | +1.0°/s | 真实**慢于**模型 | **恶化** (-6~-12%) |
| left_rate_1p3 | 1.3°/s | +1.0°/s | 真实**快于**模型 | **改善** (+2.6~+5.4%) |
| right_rate_0p7 | 0.7°/s | -1.0°/s | 真实**慢于**模型 | **恶化** (-0.6~-19.7%) |
| right_rate_1p3 | 1.3°/s | -1.0°/s | 真实**快于**模型 | 中性 (~0%) |

**规律：当真实转弯比 CT 模型假设的快时，自适应有正收益；当真实转弯比模型慢时，自适应有害。**

## 三、瓶颈诊断

### 真正的瓶颈：CT 模型的 turn_rate 参数与真实不匹配

IMM 的 CT 模型用固定的 `turn_rate_rad_per_sec = ±1.0°/s`（来自 `simulation_params_oracle.m` L162）。但真值是 0.7°/s 或 1.3°/s。

- 当真实 = 0.7°/s（慢于模型 1°/s）：CT 模型预测的转弯太急 → 新息大 → mu(CT) 被压低 → 此时若 Sigmoid 再压低 P_CT→CV 让 CT 粘住，会**延长错误模型的存活** → 误差累积 → 恶化
- 当真实 = 1.3°/s（快于模型 1°/s）：CT 模型预测的转弯太缓 → 但方向对 → Sigmoid 让 CT 粘住反而**给了模型更多时间收敛** → 改善

**PI 调整（Sigmoid）治标不治本**。真正的病灶是 CT 模型的转弯率假设错误。

### 为什么之前的结论是错的

Phase 3/4 报告在 47° 小转弯上得到 "+6% 改善"，是因为：
1. 小转弯持续时间短（67s/36s），滤波器还没收敛就结束了
2. Config#51 的高 Q_scale(5.3) 让 CT 在短转弯上表现尚可
3. Sigmoid bug 版本实际上没生效（等于 Config#51 alone）

换成真 180° 大转弯（持续 257s/138s）后，滤波器有足够时间暴露 CT 模型 turn_rate 不匹配的问题，所有 PI 调整都救不了。

## 四、下一步方向

### 方向 A：CT 模型 turn_rate 自适应（推荐，治本）

放弃在 PI 上做文章，转而让 CT 模型的 `turn_rate` 参数自身自适应。两种实现：

1. **多模型扩展**：把 CT-left 拆成 CT-left-slow(0.5°/s) + CT-left-fast(2°/s)，IMM 变成 5 模型（CV, CTL-slow, CTL-fast, CTR-slow, CTR-fast）。模型间自动选最匹配的。
2. **参数估计**：用新息序列在线估计 turn_rate（类似自适应 UKF 的 Q 估计，但估计的是运动学参数 ω）。

方向 1 改动小（只扩 Pi 矩阵到 5×5 + 多建 2 个 UKF），方向 2 改动大但理论上更优。

### 方向 B：放弃 IMM，改用 VS-IMM 或 STF

- **VS-IMM**（Variable Structure IMM）：根据新息动态增删模型
- **STF**（Strong Tracking Filter）：用渐消记忆因子强制新息正交

这些是学术界处理机动跟踪的标准进阶方法。

### 方向 C：诚实写"问题分析"论文

如果时间紧，可以写一篇"IMM-UKF 在 OTH-SWR 大转弯跟踪中的固有局限"论文：
- 揭示 PI 调整（Sigmoid/exp_decay/linear）在 turn_rate mismatch 下失效
- 用本次实验数据证明 Default 已经是最优
- 讨论 turn_rate 自适应的必要性
